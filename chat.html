Hosted models your API key

A separate list from the GPU models above. These run on other companies' servers, so the scene leaves this browser. Varden hosts nothing here: you paste your own OpenRouter key, it stays on this device, and the request goes straight to them.

Keyless models no key · shared

A third list, separate from both above: a public endpoint anyone can call without an account. Nothing is billed, but nothing is private either — the scene goes to a shared pool run by someone else, at whatever speed their queue allows, and it can change without notice.

Send the scene off this device?

The pool runs on someone else's servers, so from the next reply on, everything in this chat goes there: your words, the character's card, the persona you play and the author's note. There is no key, no account and no agreement between you and whoever operates it, and the whole exchange is often logged. Anything you would not say to a stranger probably belongs on a local model instead. Asked once per browser; switching back is instant.

Own server no account · your machine

A fourth route for anyone running Ollama, LM Studio, llama.cpp or vLLM: point Varden at it and the scene goes to that address and nowhere else. No account, no bill, and the only remote route that can use a truly uncensored model — the five Hermes and OpenHermes entries in the GPU list are the local equivalents.

The server must allow this page's origin (Ollama: OLLAMA_ORIGINS) and your browser may ask once for permission to reach your local network. The key, if you use one, stays in this tab only. Local GPU inference is still the only route where nothing leaves the machine at all.

Devices optional

Optional: let the scene drive a toy you own as the reply arrives. It works on every route, including the local GPU one, because only intensity numbers ever leave this page — never the words, the card or the persona. Off by default, and nothing moves until you press Connect.

Set up a device

Phone or PC running Lovense Remote with Game Mode switched on: the app shows a LAN IP, and that is what goes here. Your browser will ask once for permission to reach the local network.

Runs on this computer, so nothing leaves the machine and no browser permission is needed. Install Intiface Central, start its server, and connect the toy there first.

Unlike the two above, The Handy is driven through its vendor's cloud, so commands travel over the internet and the connection key identifies your device to them. Still only intensity, speed and position — no text. The stroker keeps running if this tab dies, so Stop is not optional here.
